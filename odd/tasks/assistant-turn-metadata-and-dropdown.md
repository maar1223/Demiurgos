Delivery: work-unit commits on the feature branch; no push/PR/release unless the Owner asks.
Runners: `cd frontend && npx vitest run`; `npm run typecheck`; `npm run build` (the API serves `frontend/dist`).

## Specs

- **S1** The Owner's request, verbatim: "hazlo tu y sigamos adelante con el segundo frente".
  The accepted plan is FRENTE 2 of the checkpoint L4 entry ("ok, haz una lista de todo lo que tenemos que hacer para comenzarlo en una nueva sesion. Guardalo en checkpoint y lo comenzamos con contexto fresco"): measure the duration and what the turn consulted, and show them per response.
- **S2** Measure in `useAIAssistantSessions.sendMessage`: `startedAt` when the turn starts and `durationMs` when it closes, on the same wall clock as the visible `ElapsedTime` timer. The metadata is attached to the assistant message the turn produced, **including failed turns** (the blocked copy is still a turn that took time and consulted sources).
- **S3** Extend `Message` with `turn?: { durationMs: number; items: AssistantActivityItem[]; sources: string[]; warnings: string[] }`. No migration: messages persisted before this change carry no `turn` and render nothing extra.
- **S4** Render: one collapsible block, closed by default, under each assistant bubble, summarising "Tardó 27 s · Consultó 3 fuentes"; inside, every operation with its status and the confirmed sources. Reuse `isSafeEvidencePath`, `activityOperationLabel`, `activityStatusLabel` and `safeActivityWarning` — no second sanitizer.
- **S5** The live `ActivityEvidence` panel renders only while `isSending`; once the answer arrives the information lives in the collapsed block. Turn `ACTIVITY_EVIDENCE_UI_ENABLED` on (`AIAssistantSidebar.tsx`).
- **S7** The Owner's decision, verbatim: "Contar las fichas inyectadas (Recomendada)".
  Acceptance: the turn reports the fichas the **backend** injected into the prompt, not only the graph tools the model called. `_build_ai_ask_prompt` collects the paths from the same search that builds the context block, and the SSE stream emits one `activity` item per path with operation `World context` (`running` then `succeeded`, the client reducer's ordering contract), after validating containment with `validate_structured_world_path`. Provider claims still never become evidence: this is the server's own record of files it read.
- **S8** The Owner's question, verbatim: "porque confirmó todas esas fuentes cuando la pregunta era tan especifica?" — and the decision, verbatim: "Tokenizador + conteo honesto (Recomendada)".
  Acceptance: (a) query tokenization strips punctuation, so a question like "¿Quién es Ganic?" retrieves `personajes/ganic.md` first instead of dropping the entity name (`ganic?` matched nothing); (b) "consultó fuentes" counts only paths the **model** read through the graph tools, and the fichas the backend injected are reported separately as context ("Contexto: N fichas" in the collapsed summary, "Contexto inyectado (N)" in the live panel). The injection cap stays at `MAX_GRAPH_HITS = 5`: the measured sibling scores (77–83% of the top hit) show ranking is not reliable enough to cut context without risking a blind assistant.
- **S9** The Owner's question, verbatim: "cual es la diferencia entre consulta y contexto que no me queda muy claro (y la UI no lo deja claro tampoco)".
  Acceptance: the two mechanisms are named differently and explained in the UI. A **graph call** is what the model does mid-turn (`graph_search`/`graph_read`): the count and each status are exact, but the file is unknown because Hermes never exposes a tool result (`_translate_started`/`_translate_completed` set no path). **Injected context** is what the server pastes into the prompt before the turn: exact paths. The collapsed summary reads "N consultas al grafo · Contexto: M fichas", the expanded panel explains the difference in one line, and no UI copy ever claims a file for a tool call.
- **S6** i18n `es`/`en` in `frontend/src/i18n/messages.ts` with parity (enforced by `catalogueGuard.test.ts`), and tests: the hook persists `durationMs` on a successful turn, on a failed turn, and leaves a legacy message without `turn` alone; the block renders collapsed with the summary and opens to show operations and sources; the live panel disappears once the turn closes.
