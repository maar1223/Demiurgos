# Eneagrama↔Stal — Vibrantes Canon

These files define the personality format for **Vibrantes** canon. The Eneagrama personality system (`e1_perfeccionista.md` through `e9_pacificador.md`) is bridged with the **Stal** power system via `00_eneagrama_stal.md`.

## Canon Status

The e1–e9 personality profiles are **Vibrantes canon**. They describe the core personality archetypes that drive character motivation in this world. Each profile intersects with the Stal power system at specific points documented in the bridge file.

## Usage

Consult these profiles during character creation (`skills/crear_personaje.md`) when the character belongs to the Vibrantes world. The bridge document maps each eneatipo to its corresponding Stal power manifestation.

## Naming Convention

All filenames in this directory follow **lowercase snake_case** — the durable naming contract for this project.
